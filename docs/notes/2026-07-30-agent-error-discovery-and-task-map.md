# Agent 错误发现、任务地图与多区域展示 — 设计笔记

日期：2026-07-30 · 触发：goal「如何发现 agent 中的错误（err、lost in the middle）；
是否需要任务地图；交互页面多展示区域是否更好」

## 1. 错误发现：按可测性分三层，lost-in-the-middle 有了首个测量

### 错误分类学与现状

| 层 | 例 | 现状 |
|---|---|---|
| 机械错误 | 工具报错、provider 失速、超大消息 | ✅ doctor 6+3 规则、guards |
| 行为错误 | 策略打转、悬空结局、重复提问 | ✅ `--autopsy` 报告层（不设阈值）|
| **认知错误** | lost in the middle：忘记早先约束/已读内容、重复劳动、基于过期状态行动 | ⚠️ 信号已埋、未成仪器 |

### lost-in-the-middle 的确定性代理信号（全部已在采集）

- **repeat_reads**（同路径+选择器重读）— "忘了自己看过什么"
- **identical command re-runs** — "忘了自己做过什么"
- **edit_rejections / hashline 过期标签拒绝** — "基于过期的文件记忆行动"
- **intent 填充率下滑** — 注意力金丝雀（同源免疫）
- **thinking-collapse** — 已有规则，工具密集会话中偏弱

### 首个位置分解测量（2026-07-30，3 个 ≥300 消息的真实会话）

按会话四分位统计：**重复类信号后倾成立于 2/3 会话** ——
邮件事故 re-reads 0→7→13→9、cmd-reruns 0→1→3→3；本会话（843 msgs）尾段
re-reads 1、reruns 2；开发长会话（1760 msgs）零重读（选择器纪律好）。
**error rate 是 U 形**（Q1 开局摸索期错误率最高），朴素的"错误率上升"检测
会被开局噪声淹没——**位置分解的仪器必须用重复类信号，不能用错误率**。

### 结论与路线

1. 候选规则「repetition-trend」：会话后半重复类事件密度 ≥ k× 前半。
   n=3 不足以定 k —— 进 incidents.md 候选池，等结局标签积累后校准
   （现在有 `omp label` 了，被标 abandoned 的会话就是校准集）。
2. 指令违背类认知错误（早期约束晚期违反）无确定性判据 → 离线弱模型评审层，
   先人工标注对齐，纪律同前。

## 2. 任务地图：要，但必须是「派生的」，不能是「宣称的」

关键证据：邮件事故 457 条消息只调了 2 次 todo——**模型不可靠维护的地图 =
过期地图 = 比没有更糟**（给人假态势）。而 declared/derived 的分野本身就是仪器：

```
地图 = 宣称意图（todo/plan） × 派生轨迹（实际行为）
二者的背离，正是"漂移"的定义 —— 也正是用户最想在形成期看到的东西
```

派生轨迹的原料全部已有：命令谱系（autopsy 已算，可活化）、stage timings、
todo 状态、错误簇。不需要模型配合，不会过期，不增加提示词重量
（AHE：prompt 手术负收益；派生展示零 prompt 成本）。

## 3. 多展示区域：先叠加层（overlay），不做常驻分栏

| 方案 | 成本 | 判断 |
|---|---|---|
| 常驻分栏（side pane）| 永久占用终端空间；重度偏离上游 UI（上游每小时迭代，fork 维护成本高）| ❌ 暂缓 |
| **可呼出叠加层 `/map`** | 上游惯用形态（plan-toc、agent-dashboard、/health 全是先例）；只在被召唤时付费 | ✅ 首选 |
| 状态栏微地图段 | `todo 3/7 · phase:实现 · ↻47` 一段十几个字符 | ✅ 可选加装 |

与既有决策一致：状态栏 = 指示灯不是报告（✓ 心跳的裁决）；警报疲劳 > 无警报。
常驻分栏是"永远在报告"，违反该原则；叠加层是"问了才报告"。
若 `/map` 被高频呼出（可测：命令使用计数），那才是常驻分栏的立项证据。

## 落地顺序

1. `/map` 叠加层：todo 状态 + 派生轨迹条（近 N 轮工具/错误/主导前缀计数）+
   背离提示（todo 长期未动而命令谱系高速滚动 = 宣称与行为脱节）。
2. repetition-trend 候选进 incidents.md，等标签语料校准。
3. 状态栏微地图段随 1 顺带评估。
4. 常驻分栏：仅当 1 的使用频率证明需要。
