## Failure evidence

Incident #1 (Mail session `019fac75`): the user watched a live stream of tool
calls with no way to see the trajectory forming — 120 near-identical browser
invocations accumulated before anyone could name the pattern. The declared
plan was no help: todo was called twice in 457 messages, so the only
"task map" in the session was stale from the first hour. Post-hoc, the
`--autopsy` command lineage made the drift obvious in one glance — but only
after the task had already been abandoned to manual takeover.

Design note `docs/notes/2026-07-30-agent-error-discovery-and-task-map.md`
records the analysis: a model-maintained map goes stale (declared-only fails);
a derived map cannot go stale; and the *divergence* between declared and
derived is itself the drift signal users need earliest.

## Root cause

The interactive surface has no trajectory view. Declared intent (todo phases)
and actual behavior (command stream) are both recorded but never juxtaposed;
each is invisible to the other, so their divergence — the earliest deterministic
sign of an agent grinding off-plan — is computed nowhere.

## Targeted fix

Pure `buildTaskMap(entries, todoPhases)` in `src/health/map.ts` over the live
session entries (same shapes the autopsy consumes):

- **declared**: phase progress (done/total per phase, current in-progress
  task), plus turns since the last todo tool call;
- **derived** (trailing window of 30 assistant turns): tool-call counts by
  tool, error count, dominant command prefix with count (live churn counter),
  repetition counters (same path+selector re-reads, byte-identical re-runs) —
  the lost-in-the-middle proxies from the position-resolved measurement;
- **divergence** (deterministic, display-only): flagged when todos exist but
  the last todo update is ≥15 commands old ("declared plan may be stale"), or
  when no todos exist after ≥20 assistant turns ("no declared plan").

`/map` slash command beside `/health` (same `runtime.output` idiom):
autocomplete shows a one-line summary, invocation prints the map. Display
only; no ledger writes, no thresholds beyond the divergence heuristics, which
judge staleness of *declarations*, not quality of behavior.
