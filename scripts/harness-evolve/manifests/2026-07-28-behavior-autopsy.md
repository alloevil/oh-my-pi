## Root cause

The health stack measures the mechanical layer only. Behavioral evidence
exists in every transcript but requires ad-hoc extraction, so investigations
collapse onto whatever the tools already display.

## Targeted fix

Pure `buildAutopsy(entries)` in `src/health/autopsy.ts` returning a structured
report; `omp doctor <session> --autopsy` renders it. Sections, all computed,
none judged:

1. **Errors** — failed tool results clustered by (tool, first line ≤80 chars):
   total, distinct clusters, top clusters with counts.
2. **Command lineage** — bash/eval commands clustered by first line ≤80 chars:
   top repeated prefixes with counts.
3. **Ending** — last message role, last assistant text head (120 chars),
   whether the transcript ends with an in-flight assistant turn, todo call
   count.
4. **Asks** — count, per-ask question text (first question, ≤80 chars), and
   execution duration per ask from stage timings where recorded.

Display-only: no severities, no findings, no ledger writes. Incident ledger
(`incidents.md`) records observed-but-unruled pathologies so the second
occurrence of a pattern has a place to match against before a rule is carded.
